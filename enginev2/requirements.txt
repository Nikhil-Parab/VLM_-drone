# ================================================================
# Raspberry Pi notes
# ================================================================
# Install:
#   pip install -r requirements.txt --break-system-packages
#
# torch on ARM (Pi 4/5):
#   The default pip wheel may not exist for your ARM build.
#   Use piwheels or the official PyTorch ARM page:
#     https://pytorch.org/get-started/locally/
#   Or install from piwheels:
#     pip install torch --index-url https://www.piwheels.org/simple
#
# SmolVLM-256M-Instruct downloads ~987 MB from HuggingFace on first run.
#   Requires a 32 GB+ SD card (an 8 GB card won't fit OS + packages + model).
#
# pyaudio on Pi:
#   sudo apt-get install portaudio19-dev python3-pyaudio
#   pip install pyaudio
#
# Vosk offline model (if using offline voice backend):
#   wget https://alphacephei.com/vosk/models/vosk-model-small-en-us-0.15.zip
#   unzip vosk-model-small-en-us-0.15.zip
#   (place folder next to voice_command_interface.py)
